# Сборка DUMPLINCH EGG HUNT APK только с Android-телефона

## Что подготовлено
- Godot 4.3.
- Android export preset: `org.dumplinch.egghunt`.
- Только ARM64 (`arm64-v8a`).
- GitHub Actions workflow `.github/workflows/build-apk.yml`.
- Облачная сборка создаёт временную debug-подпись и APK для тестирования.
- APK сохраняется в GitHub Actions Artifacts на 14 дней.

## Самый простой путь с телефона
Для облачной сборки нужен GitHub-репозиторий. Не загружайте ZIP как единственный файл репозитория: GitHub Actions не распакует его автоматически.

1. Создайте новый репозиторий на https://github.com/new (например, `dumplinch-egg-hunt`).
2. Загрузите **содержимое этой папки проекта** в корень репозитория. В корне GitHub должны быть видны `project.godot`, `scenes/`, `scripts/`, `shaders/`, `export_presets.cfg` и `.github/`.
   Не создавайте дополнительную внешнюю папку `dumplinch/` внутри репозитория.
3. Откройте вкладку **Actions** в репозитории. Если GitHub спросит разрешение на запуск Actions, подтвердите его.
4. Выберите workflow **Build Android APK**.
5. Нажмите **Run workflow** → **Run workflow**.
6. Дождитесь завершения. Зелёная галочка означает, что все проверки и сборка прошли.
7. Откройте завершённый запуск workflow и найдите раздел **Artifacts** внизу страницы.
8. Скачайте `DumplinchEggHunt-Android-ARM64-debug`.
9. Распакуйте скачанный архив на телефоне. Внутри будет `DumplinchEggHunt.apk`.
10. Откройте APK и разрешите установку из этого источника, если Android спросит.

## Важно
- Для первого теста используется debug-подпись. Это не релизная подпись для RuStore.
- При новой сборке с другим debug-ключом Android может не разрешить обновить предыдущую установку поверх старой. Тогда удали тестовую версию и установи новую. Сохранения в `user://` при удалении приложения могут пропасть.
- Не публикуй debug APK как финальный релиз.
- Не загружай секретные release keystore или пароли в публичный репозиторий.
- Сборка пока не подтверждена реальным запуском: GitHub Actions выполнит импорт, проверку скриптов, дымовой тест и экспорт. Если шаг упадёт, открой лог этого шага и пришли его сюда.

## Важное о телефоне
Обычный браузер Android позволяет создать репозиторий и управлять Actions, но загрузка множества папок через мобильный интерфейс GitHub может быть неудобной. Если загрузка структуры окажется невозможной, подключение GitHub к ChatGPT позволит проверить репозиторий и упростить дальнейшие правки; само подключение требует твоего подтверждения.
