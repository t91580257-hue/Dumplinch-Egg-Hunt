# DUMPLINCH EGG HUNT

3D-игра для Android на **Godot 4.3** (GDScript, рендерер Mobile/Vulkan): охота за яйцами, питомцы, пять регионов, десять боссов.
Package ID: `org.dumplinch.egghunt`, архитектура ARM64.

> **Честный статус.** Проект написан без доступа к редактору Godot, поэтому **ни разу не запускался и не тестировался**:
> ни на ПК, ни на Android. Возможны ошибки парсера и рантайма. Первым делом откройте проект в Godot 4.3, посмотрите панель
> «Ошибки» и запустите `scripts/tools/validate_project.gd` (см. ниже). FPS не измерялся — цифры 30/60 FPS пока лишь цель.
> Все модели, текстуры и звуки **процедурные** (создаются кодом из примитивов), готовых импортированных ассетов нет.

## Как открыть проект
1. Установите Godot **4.3** (стандартная версия, не .NET): https://godotengine.org/download
2. Project Manager → Import → выберите `project.godot` → Open. Первый импорт займёт минуту.
3. F5 — запуск (главная сцена `scenes/main.tscn`).

### Управление на ПК
WASD — движение, Shift — спринт, Space — прыжок, J — атака, K — особая атака, L — уклонение, F — действие
(взять яйцо, открыть сундук/врата), P — вызов питомцев, G — танец, Q/E или правая кнопка мыши — камера, колесо — зум.
Кнопки на экране нажимаются мышью.

### Управление на телефоне
Левая половина экрана — плавающий джойстик (чем дальше тянете, тем быстрее: шаг, бег, спринт). Правая — свайп камеры,
щипок двумя пальцами — зум. Кнопки справа внизу: атака, прыжок, особая, уклонение, действие, вызов питомцев (мультитач).
Размер кнопок и чувствительность камеры — в «Настройках».

## Как собрать APK
### Вариант 1: GitHub Actions (рекомендуется)
Залейте проект в репозиторий GitHub. Workflow `.github/workflows/build-apk.yml` сам: скачает Godot 4.3 и шаблоны экспорта,
поставит Android SDK/JDK 17, создаст **временный отладочный ключ**, импортирует ресурсы, проверит проект
(`validate_project.gd`), прогонит дымовой тест (`smoke_test.gd`), экспортирует APK и загрузит его как Artifact
`DumplinchEggHunt-apk`. Ключей подписи в репозитории нет. Для релиза в Google Play создайте свой keystore и храните его в GitHub Secrets.

### Вариант 2: локально
1. Установите JDK 17 и Android SDK (build-tools 34.0.0, platform android-34).
2. Godot → Editor → Editor Settings → Export → Android: укажите пути к SDK и JDK, создайте debug keystore.
3. Editor → Manage Export Templates → Download and Install.
4. Project → Export → пресет **Android** (уже настроен: ARM64, `org.dumplinch.egghunt`) → Export Project (debug).

## Структура
```
scenes/main.tscn        единственная сцена, всё остальное строится кодом
scripts/autoload/       GameData (все данные), GameState (прогресс, валюты, квесты), SaveSystem, AudioManager
scripts/player/         player.gd (управление, модель, анимации, бой), camera_rig.gd
scripts/enemies/        enemy.gd, boss.gd, projectile.gd
scripts/pets/           pet_builder, egg_builder, pet_manager, egg_opening
scripts/world/          world.gd (регионы, день/ночь, погода) + объекты: egg_pickup, chest, gate, heal_well, breakable
scripts/ui/             HUD, окна, мини-карта, мобильное управление, главное меню
scripts/vfx/, util/     эффекты, процедурные текстуры
scripts/tools/          validate_project.gd, smoke_test.gd
shaders/                grass.gdshader (ветер), water.gdshader (вода, лёд, лава)
```
Папки `models/ textures/ audio/ materials/ animations/ particles/ ui/ environments/ pets/ bosses/ items/ resources/ addons/`
созданы под будущие импортированные ассеты (сейчас в них только `.gdkeep`).

## Что реализовано
- **Герой Dumplinch**: процедурная модель пельменя (тесто с текстурой, защипы, шапка, ножки, ручки, глаза), 14 состояний
  анимации (idle, walk, run, sprint, jump, fall, land, attack, special, damage, victory, defeat, open_egg, dance) с плавным
  смешиванием; повороты по направлению движения, разгон/торможение.
- **Камера**: от третьего лица, свайп, зум, SpringArm (не проходит сквозь землю и объекты), тряска, кинематографические
  режимы (открытие яйца, победа над боссом), облёт в меню.
- **Мир**: 5 регионов по 260x260 м подряд (Зелёные Холмы, Ледяная Долина, Огненные Земли, Небесные Острова, Тёмное
  Королевство), у каждого своя палитра неба/тумана/земли, музыка, враги, яйца, погода и декор. День/ночь (7 минут),
  ветер в траве (шейдер), облака, птицы, бабочки, светлячки ночью, листопад/снег/искры/споры, вода, лава (наносит урон),
  разрушаемые ящики, сундуки, колодец-лекарь, врата между регионами.
- **Яйца**: 15 видов, свой цвет, узор-текстура, свечение, частицы, цена и шансы; открытие с кинокамерой (вращение,
  свечение, тряска, трещины, вспышка, появление питомца с названием и редкостью); быстрое открытие и пачка до x10.
- **Питомцы**: 30 штук (10 форм моделей), инвентарь, экипировка (слоты), избранное, сортировка/фильтр по редкости,
  уровни, объединение 3 одинаковых (звёзды), эволюция (формы), способности (+урон, +монеты, +опыт, +скорость).
  Следуют за героем, сами атакуют цель, «вызов питомцев» даёт тройной удар.
- **Бой**: атака с автонаведением, особая атака по площади, уклонение с неуязвимостью, критические удары, цифры урона,
  вспышки, вибрация, звуки, перезарядки. Прыжок спасает от ударных волн боссов.
- **10 боссов** с пробуждением, тремя фазами, атаками (удар по площади, рывок, залп, нова), наградами, музыкой боя и
  анимацией поражения; финальный — Король Яиц.
- **Экономика**: монеты, самоцветы, кристаллы, жетоны; магазин (яйца, усиления героя, слоты, ускорители, шапки);
  все покупки имеют реальный эффект.
- **Прогресс**: уровни и опыт, титулы, сюжетные (14), побочные, секретные, ежедневные задания, достижения, ежедневная награда.
- **Интерфейс** на русском: HUD, мини-карта, карта мира, инвентарь, питомцы, магазин, задания, достижения и коллекции
  яиц/боссов (вкладки одного окна), настройки (громкость, камера, кнопки, качество, вибрация).
- **Звук**: все эффекты и музыка синтезируются кодом (свободны от лицензий), три шины громкости: Music / SFX / UI.
- **Сохранения**: JSON в `user://`, резервная копия, автосохранение каждые 30 с, при сворачивании и выходе.
- **Графика**: три режима (Низкий/Средний/Высокий) меняют разрешение рендера, тени, свечение, плотность декора и частицы.

## Ограничения и что дальше
- Проект **не запускался**: ожидайте исправлений после первого запуска (см. статус выше).
- Модели и анимации процедурные (примитивы, без скелета). Ссылка на референс Dumplinch **не загружалась** (в среде
  разработки не было сети), поэтому внешность — приближение; цвета и детали модели правятся в `player.gd::_build_model()`.
  Для настоящей модели добавьте `.glb` в `models/` и подмените `_build_model()`.
- Небесные острова — декор над облачным полом (по ним нельзя ходить). Нет настоящих LOD и occlusion culling (используются
  MultiMesh, дальность камеры и снижение плотности декора). Деревья — MultiMesh, коллизии лишь у части.
- Музыка — короткие зацикленные синтез-мелодии, генерируются при первом включении (возможна короткая пауза).
- Баланс не настроен. Уникальные анимации боссов — лишь общие (появление, рывок, поражение).
- Мультиплеер (друзья, совместные яйца, групповые бои, обмен питомцами, общий хаб) **не реализован** — будущая функция.
  Состояние игрока изолировано в `GameState`, что упростит добавление сети.
- Проверка проекта: `godot --headless --path . --script res://scripts/tools/validate_project.gd`;
  дымовой тест: `godot --headless --path . --script res://scripts/tools/smoke_test.gd`.
